- **Do not use `ts.createSourceFile` from `node_modules/typescript`:** `typescript@7.0.2` (`tsgo`) throws `Error: The JavaScript API for TypeScript 7.0 is not yet implemented`. Use `Bun.Transpiler.scan()` + the Depth-2 closure-factory state machine (`WF-SUB-R03` / `WF-SUB-05`).
- **Do not use `write_to_file` on unaccepted external workspace files without immediate git commit:** Writing to `/Users/MAC/Documents/coding-projects/hivemind-substrate` via IDE buffer tools without committing can result in `0`-byte buffer resets. Write via shell/script and atomic-commit immediately.
- **Do not key `delegation` by `(parent_session_id, child_session_id)`:** A resumed child session (`mode = "send"`) has multiple turns under the same `child_session_id`, and `child_session_id` can be `NULL` on failed spawns. Key by `(parent_session_id, call_id)` or `(child_session_id, turn_index)` (`WF-SUB-03`).
